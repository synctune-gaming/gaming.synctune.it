# Synctune Gaming

A single-page portfolio for [gaming.synctune.it](https://gaming.synctune.it).
Plain HTML and CSS, with locally bundled brand assets and fonts.
No JavaScript, dependencies, install command or build step.

- [Preview and manual Pages deployment](docs/deployment.md)
- [Content, project links and brand assets](docs/maintenance.md)

The repository root is the publish directory. Nothing deploys automatically.
